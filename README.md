# Nest Gen 2 Thermostat Documentation

This repository contains documentation derived from exploring the Nest Generation 2 thermostat's application. The purpose is to provide developers with information on its internal workings, enabling the creation of compatible servers or tools for continued use after official support has ended.

## Purpose
Google acquired Nest and later discontinued remote/app access for the Nest Gen 2, rendering it non-smart without alternatives. This documentation aims to support interoperability and personal use, such as integrating with custom home automation systems.
